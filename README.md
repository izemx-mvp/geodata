# GEODATA Flow

Create a complete, professional and functional MVP web application for:

GEODATA – AI Business & Project Management Platform

The application is an internal intelligent platform for GEODATA, a Moroccan company specializing in:

- Topography

- Geodesy

- Photogrammetry

- LIDAR / 3D Mapping

- Mobile Mapping

- GIS / SIG

- Cartography

- Land surveying and land engineering

- BIM / 3D digital models

- Technical studies

- Geographic information acquisition and processing

IMPORTANT:

This is not a generic CRM.

The platform must reflect the actual operational workflow of a topography, engineering and geographic-data company.

The MVP must contain 3 main AI agents:

1. AGENT IA COMMERCIAL & RÉSEAUX SOCIAUX

2. AGENT IA APPELS D’OFFRES

3. AGENT IA LANCEMENT & SUIVI DE PROJET

All agents must work inside the same platform and share the same database.

The complete business flow must be:

Lead / Consultation / Public Tender

→ Qualification

→ Opportunity

→ Proposal / Quote

→ Internal Validation

→ Won Offer

→ Project / Affaire

→ Orders

→ Internal Orders

→ Planning

→ Execution

→ Validation

→ Internal Delivery

→ Client / Administration Control

→ Client Delivery

→ Ready for invoicing

14. MAIN OBJECTIVE OF THE MVP

--------------------------------------------------

The MVP must demonstrate one complete story:

SCENARIO A – COMMERCIAL

GEODATA receives a restricted consultation.

→ AI qualifies the request

→ Commercial prepares quote

→ Manager validates quote

→ Customer accepts

→ Opportunity becomes “Won”

→ User clicks “Lancer le projet”

→ Affair is automatically created.

SCENARIO B – PUBLIC TENDER

AI detects a public tender.

→ AI analyzes the tender

→ Gives relevance score

→ Team decides GO

→ Checklist and response dossier created

→ Offer is submitted

→ Tender is won

→ Automatically launch project.

SCENARIO C – PROJECT

Offer is won.

→ Affair created

→ Commands created

→ Internal orders created

→ Project Manager plans tasks

→ Technicians execute

→ Progress reaches 100%

→ Project Manager validates

→ Internal delivery

→ Administration checks delivery

→ Client delivery

→ Ready for invoicing

→ R1

→ Correction planning

→ Execution

→ Validation

→ New delivery
